# AVIN internal crate

This crate is part of the internal implementation of [AVIN](https://crates.io/crates/avin).

It is published separately as part of AVIN's modular workspace, but is not designed or supported for direct external use. Its API may change as the project evolves.

For normal usage, depend on the main [AVIN crate](https://crates.io/crates/avin).
